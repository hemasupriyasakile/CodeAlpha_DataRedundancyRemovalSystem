
# Data Redundancy Removal System

## About
A web-based application developed using Python Flask and SQLite to store records, prevent duplicate email entries, and maintain database accuracy.

## Features
- Add new records
- Validate name and email inputs
- Prevent duplicate email entries
- Display saved records
- Delete records
- Show success and error messages

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install Python.
2. Install Flask:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open this URL in your browser:

   http://127.0.0.1:5000

## Project Purpose
To reduce redundant records and improve data accuracy by checking existing email addresses before inserting new records.
